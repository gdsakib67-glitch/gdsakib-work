# SAKIB — Gaming Portfolio

A responsive gaming and creator portfolio for GD Sakib (`gdsakib67`). The site uses plain HTML, CSS, and JavaScript with no build step, paid service, or backend.

## Run locally

Open this folder in VS Code and open `index.html` in a browser, or use a local static-server extension such as Live Server. The site is also ready to serve as static files.

## Publish with GitHub Pages

1. Put `index.html`, `style.css`, `script.js`, and this README at the root of a GitHub repository.
2. Push the files to GitHub.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the publishing branch (usually `main`) and `/ (root)`, then save.
5. Open the Pages URL shown in the settings after deployment completes.

## Personalize

- Replace the **S** monogram inside `.avatar-placeholder` in `index.html` with your profile image. Add the image to the repository and provide an `alt` description.
- The YouTube link is `https://www.youtube.com/@Gdsakib67`.
- The Discord link is `https://discord.gg/fPrYKkeX5Y`.
- Update the project cards and descriptions in `index.html` as your portfolio grows.

The contact section links to your supplied social accounts; no form or backend is configured. Animations respect the operating system’s reduced-motion preference. Google Fonts are used when available, with system-font fallbacks.
